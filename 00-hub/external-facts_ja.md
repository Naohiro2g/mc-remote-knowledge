# 外部事実の根拠（external-facts）

外部の世界（MODローダの勢力図・ブラウザ仕様・インフラ製品の挙動・Minecraft 版の潮流など）に依存する判断の**根拠を一元管理する生きた台帳**。

[DECISIONS_ja.md](DECISIONS_ja.md) は append-only な判断ログなので、再確認で陳腐化する外部事実はこちらに逃がす。決定はここの**事実 ID**を参照し、調査日・出典・次回確認はこのファイル側で更新する（決定ログ本体は書き換えない）。

## 書き方のルール

- **事実 ID** は `F-<topic>`（小文字ケバブ）。決定からこの ID で参照する。
- **調査日** は最後に事実を確認した日（絶対日付）。再確認したら調査日と次回確認を更新する。
- **出典** は確認元（URL・仕様名・現況の観測対象など）。実値の URL は分かる範囲で具体化する。
- **状態** は `現行` / `要再確認`（次回確認を過ぎた）/ `未調査`（スロットだけ用意）。
- 事実が変わって決定に影響したら、DECISIONS に新しい行（`改訂→…`）を足す。台帳の更新だけで決定を黙って変えない。
