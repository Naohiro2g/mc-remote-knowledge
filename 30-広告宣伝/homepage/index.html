コーディングでマイクラ世界を動かす。学び方を学ぶ。

「マイクラリモコン」は、コーディングを通じて学び方を学ぶツール。 コーディングってなんなの？？という人から、各種言語の習熟者、オープンソース開発の入門者まで、8歳―80歳までの自律的な探究学習を強力に支援します。

一本道のカリキュラムではなく、Scratchによるマイクラ世界へのブロック配置、Pythonなど各種言語での自動建築、マイクラリモコン自体の改造など、いろいろな入口から入れて自由に探索できます。AIアシスト前提の学び／開発も開発者自身が模索中です。

💡 開発チームが考えていること

なぜ、今さら、マイクラをリモコン？

「マイクラをリモコンする」これは、公式のRconに始まり、マイクラアプリの代わりにプロトコルをシミュレートするものまで、様々なアプローチがすでにあるのに、なぜ、今さら「マイクラリモコン」なのか。

  • 真の目的は「学び方を学ぶ」ツールを提供し、初学者の自学学習アプローチ獲得をガイドすることだから。
  • 本物のScratch、本物のPython、Git/GitHub.comを使いたかったから。これらはオープンソース開発につながっているから。
  • その環境に慣れ親しむためのステージ、箱庭として選んだのが、マインクラフトだが、レゴ、Scratch、にも共通する手触り感のある、タンジブルな「ブロック」、これも重要な要素である。

なぜ、今さら、コーディング？？　生成AI時代には無用では？

2026年、生成AIは「マイクラみたいなアプリ」さえ作る。使い捨てアプリが目の前で生まれる今、「アプリを作ったことがある」の価値も、「アプリ」の存在意義さえも揺らいでいる。「ほとんどコードを書いていない」と公言するプログラマーも増えた。さて、コーディングをこれから学ぶ意味、ある？

2017年、コーディングを「コードを触って・変えて・観察して・判断するループの中で、創造性を引き出す行為」と捉えた。（「Coding vs. Programming（Scratch Meetup Tokyo, 2017）」、PDF）小さく試し、組み合わせ、分解して直す。ブロック遊びにも似た、この手触りにこそ創造性が宿る。

生成AIの時代に、この解釈はむしろ重みを増している。生成、打ち込みは任せていい。判断は人間が握る。「要求仕様書は満たしています」というだけの使えないアプリが量産されてきたように、元々、コードを書くだけではダメだったのだ。

だから、もちろん、学ぶ意味がある。ただ、学ぶ中身が変わる。消えるのは暗記と打ち込みの労力で、消えないのは判断のための足場だ。その足場は、目の前のTODOから始まり、ビジョンを越え、ミッションまで続いている。コードは、意図と現象をつなぐ「読める層」。AIとの協働が進むほど、相手の仕事を読めることが前提になる。マイクラの世界なら、コードを変えた結果を目で見ながら試せる。マイクラリモコンは、「手触り感のある試行錯誤」の道具を目指している。

🌍 マルチプレイ可能なアカウントで、マイクラリモコン対応サーバーに接続してみよう！
もちろん、自分で建てたサーバーで使うこともできますが、まずは、マイクラリモコン公式の箱庭サーバーに、持っているマイクラアプリ（＝クライアント）で接続してみましょう。年齢によっては、マルチプレイを可能にするために、保護者の方の操作が必要になることがあります。なお、この箱庭（サンドボックス、sb）サーバーは、定期的にリセットするため、ものすごい作品をコツコツ作る、などはやめたほうが良いです。公園の砂場と同じです。コードがあればいつでも再現できる、で行こう！

  • 接続先マインクラフトサーバー
    • サーバー名: sb-beta.mc-remote.com　（マイクラリモコン 公式 箱庭サーバー ベータ版）
    • サーバーの種類: Paper（Java、プラグインサーバー）
    • バージョン: 1.21.11（RC移行後は最新版に追従する予定。）
  • Java版クライアント (PC)
    • バージョン: ほぼ、なんでもオッケー。（プラグインViaVersion / ViaBackwards使用。）
    • ポート番号: 25565（デフォルトなので省略可能。）
  • 統合版クライアント（PC / タブレット / スマホ等）:
    • バージョン: 自動的に最新版になる。公式アップデート直後は要注意。
    • ポート番号: 25565（デフォルトの19132ではないので注意。）
⚠️ 統合版利用時の注意: マインクラフト統合版の公式大型アップデート直後は、接続用プラグインのGeyser/Floodgateの追従待ちのため、数日間接続できなくなる場合があります。
8歳からのビジュアルコーディング

🎮 Scratchで今すぐ始める

面倒なインストールは一切不要。PC／タブレット／スマホで開いたマイクラと、PC／タブレットのブラウザを使います。ブラウザのScratchで直感的にマイクラの世界を遠隔操作できます。

👉 Web版Scratchエディタ（ベータ版）を開く

🔑 マイクラサーバーとの接続とペアリング

WireScope miniに表示される ペアリングコマンド /mcremote pair NNN-NNN をゲーム内チャットに貼り付け、Enterを押すと認証が完了。コマンド先頭にスペースがあると無効なので注意。

Scratchのはじめの一歩

📍 建築原点とは？

マイクラリモコン内の座標は、全て建築原点からの相対計算になります。そのため、建築コードを共有したとき、原点さえずらせば、ピラミッドの横に大寺院を共存させられたり、同じワールドにたくさんの参加者が入った場合にも、独立した自由な建築、あるいは同じ領域でのコラボレーションが可能になります。例えば、上の例のように建築原点(200, 0, 200)で（5, 67, 5）を指定すると、実際には（205, 67, 205）にブロックが置かれます。
オープンソース開発への第一歩

🐍 PythonでのHello, world!

VS Codeなどのエディタでは自動補完でブロックIDなどが入力できる公式Pythonライブラリ。最新マインクラフトの世界へ向けて、自分のアイデアを自由にコード化できます。

まずは、ターミナルを使って簡単にPythonモジュールをインストールして、チャットメッセージの表示、きれいに輝くシーランタンブロックの配置など、試してみましょう。

Pythonモジュール（クライアント/ API）のインストール: 

pip install minecraft-remote-api -U

希望のリリースタグを指定すれば、PyPIに登録されている安定版ではなく、GitHub.comの最新版などを使うことができます。

pip install -U git+https://github.com/Naohiro2g/minecraft-remote-api.git@v2301.0.0b7.post2

ここから先は、VS CodeのJupyter Notebookで、一行ずつ実行するのもオススメ。

最小コード（hello.py）:

from mc_remote import Minecraft
# 公式箱庭サーバー（ベータ）に接続
mc = Minecraft.create(address="sb-beta.mc-remote.com", port=25575)

# 建築原点の設定
mc.setBuildOrigin(200, 0, 200)

# チャット送信
mc.postToChat("Hello, Minecraft from Python!")

# プレイヤー位置、向きの設定
mc.setPos(30, 120, 30)  # (230, 120, 230) に移動
mc.setPose(-1, -2, -1)

# ブロック設置
# 建築原点からの相対座標で (205, 67, 205) に置かれます
mc.setBlock(5, 67, 5, "sea_lantern")

🔑 実行とペアリング

python hello.py を実行後、ターミナルに表示される /mcremote pair NNN-NNN をゲーム内チャットに貼り付け、Enterを押すと認証が完了します。認証は2時間有効。

プロジェクトの起源とミッション

先人たちの功績を受け継ぎ、従来の「教育」から「学びの支援」へ。

About the Minecraft Remote Project（先人の功績と起源）

Minecraft Remote（mc-remote / マイクラリモコン）は、マインクラフトを外部からプログラムで遠隔操作するためのオープンソースシステムです。PaperMCサーバー上で動作する専用プラグイン（McRemote）と、利用者のコードを仲介するクライアントAPI（各言語版）から構成されています。

本プロジェクトは、RaspberryJuice（zhuowei氏）、mcpi（Martin O'Hanlon氏）、JuicyraspberryPie（wensheng氏）といった先人たちの先駆的な功績と、コミュニティの英知を受け継ぎ、最新のマインクラフト環境へ向けて再構築したものです。

「私たちは、知識を一方的に注入する従来の『教育（EDUCATION）』ではなく、学習者が自ら探究し創り出す『学びの支援（SUPPORT LEARNING）』を目指しています。この思想は、MITメディアラボ ライフロング・キンダーガーテン（Dr. Mitchel Resnick）の精神に強く影響を受けています。」

先人たちのプロジェクトリファレンス:

  • RaspberryJuice by zhuowei
  • mcpi by Martin O'Hanlon
  • JuicyraspberryPie by wensheng
  • MIT Media Lab Lifelong Kindergarten

The Clear Mission（明確なミッション）

初学者が自学自習アプローチ（Self-Learning Approach）を獲得できるよう支援すること。 単なるプログラミング言語の文法や技術スキルの習得にとどまらず、「自分で課題を発見し、試し、学ぶ姿勢」を育むことを最上位の目的としています。コーディング「を」学ぶ、ではなく、コーディング「で」学ぶ。

（結果的に）獲得される3つの技術スキル

  • コーディングの本質的な概念と技術
  • Git/GitHubを活用した実践的なオープンソース（OSS）開発技術
  • 自分のアイデアを形にし、世界に表現する技術

自立的な学びのモチベーションを保つ仕掛け

  • 魅力的な実験場（Sandbox）として最新版マインクラフトを常に利用可能にする
  • 過去のプロジェクトで培われたコード資産を活用・再利用できるようにする
  • Scratch、Python、Java、TypeScript / JavaScript、C#（Unity）など、幅広い言語と環境へ展開できる
  • マインクラフトの世界にとどまらず、BlenderやHoudini等の3D環境、デジタルと現実を結ぶ入出力、AI技術（コンピュータビジョン・機械学習との連携）へ発展できる

エコシステム・各リポジトリ案内

マイクラリモコンを構成するオープンソースリポジトリ群です。

🔌 McRemote

（プラグイン／mc-remoteサーバー）

PaperMCサーバー上で動作する専用プラグイン。JSON-RPC 2.0プロトコルによる高速・安全な接続エンジン。mc-remote（マイクラリモコン）サーバーとして動作。

GitHubで見る →

🐱 scratch-editor

（mc-remoteクライアント）

ブラウザだけで動くWeb版Scratchエディタ（Scratch 3.0 フォーク＝改造版）。インストール不要で、IndexedDBによる作品自動保存にも対応。

GitHubで見る →

🐍 minecraft-remote-api

（mc-remoteクライアント）

標準APIを備えた公式Pythonクライアントパッケージ。ブロックID、エンティティIDのカタログ補完機能を提供。

GitHubで見る →

🔍 WireScope

（ワイヤースコープ / ライブ画面）

クライアントとサーバーの間を行き来する通信内容（ワイヤメッセージ）をリアルタイムに覗き見できる観察・学習ツール。現在、ScratchやPythonクライアントと連携可能。

WireScope Betaを開く →

☕ minecraft-remote-java

（mc-remoteクライアント）

Java環境からmc-remoteサーバーに接続して制御するためのJavaクライアントライブラリ。

GitHubで見る →

🎮 minecraft_remote_unity

（サーバー／クライアント）

Unityで利用可能なC#サーバー／クライアント。mc-remoteサーバー／クライアントとの相互接続で、Pythonで書いてUnity世界に建築、C#でマイクラ世界に建築、などが可能。（※旧プロトコル対応）

GitHubで見る →

📦 mc-remote-stack

（デプロイツール）

マイクラサーバー・Bridge・Scratch・WireScopeの一括構築・運用を支援する公式パッケージ。

GitHubで見る →

📖 mc-remote-knowledge

（知識データベース）

システム全体のアーキテクチャ、決定ログ（DECISIONS）、プロトコル契約、設計思想を管理する真実の源（SSOT）。LLM支援前提のナレッジベース型開発支援システムの根幹。

GitHubで見る →
