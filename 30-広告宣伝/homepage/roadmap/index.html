開発ロードマップ & 進捗状況

2027年春の教室本番導入に向けた公開ロードマップです。

● 現在地: R3（学べる・教えられる）進行中 / rc1 公開中
  • 2026年8月末
    b6 / Protocol 23.0.0: 看板（Sign）API、ツルハシ叩き（poke）イベント、ブラウザ内自動保存の統合。
  • 2026年9月前半【完了】
    b7 / Protocol 23.1.0: プレイヤーおよびエンティティの方向（direction）操作、落雷（lightning）、WireScope detached ZIP同梱。ホームページ骨格・README近代化（Pass A）。
  • 2026年10月3日【公開】
    b8 / Protocol 23.2.0: エンティティライフサイクル（近くのエンティティの検索、位置と向き、削除）、パーティクルStage 2（色・大きさ、見せる相手）、サウンド（位置とブロックの音）。Pythonの短いimport。Windowsでの導入手順の確認。
  • 2026年10月5日【公開】
    b9 / Protocol 23.2.0: APIフリーズ（初回Stableまで、APIは追加・変更しない）。PythonモジュールをPyPIへ登録（ベータ版は版を指定して取得）。プロトコル定義、WireScope、Bridgeを共通の開発基盤リポジトリ（minecraft-remote-tooling）へ移管。
  • 2026年10月14日【公開】
    b10 / Protocol 23.2.0: 一つのプラグインでPaper 1.21.11と26.3の両方に対応。大きな範囲のブロック設置を、サーバーを止めないよう少しずつ施工。Scratch LANパッケージ（Windows／macOS／Linux用）で、自分のPCや家庭・教室のネットワークでもScratchから操作できるように。
  • 2026年10月19日【公開】
    rc1 / Protocol 23.2.1: 初回Stableのリリース候補（Release Candidate）。APIはb10と同じで、Protocol 23.2.0のサーバー・クライアントともつながる。Scratchのブロック選びで、マイクラ26.3で増えたブロックも日本語の名前で探せるように。Scratch LANパッケージのはじめに.htmlを、OSごとの手順に整理。
  • 2026年11月
    初回 Stable リリース（2321.0.0）: 安定導入手順と公式サポート版の公開。箱庭サーバーsb.mc-remote.comが新しいプロトコルの安定版になり、旧プロトコルのサーバーはsb-retro.mc-remote.comへ（11月末まで）。旧版からの移行は移行スケジュールへ。
  • 2026年11月
    2321.1.0: Stableを出した後の改善。PythonでWireScopeを使うときの観測の始まりと終わり、Scratch LANパッケージのランチャーとはじめに.htmlなど。
  • 2026年12月
    2330.0.0 ベータ版: サウンドの拡張。旧プロトコルのsb-retro.mc-remote.comを終え、箱庭サーバーは新しいプロトコルの安定版（sb.mc-remote.com）とベータ版（sb-beta.mc-remote.com）の二つになります。
  • 2027年春（4月）
    新学年・教室本番導入: 確定したStable環境での教材運用開始。独自Mobやエージェント型建築カリキュラムへの発展。
