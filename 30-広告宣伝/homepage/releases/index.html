📜 過去のリリース履歴を展開して確認する
  • 2026年10月19日Protocol 23.2.1 (rc1)
    初回Stableのリリース候補。Protocolを23.2.1、配布版を2321.0.0rc1に（APIと通信の中身はb10と同じで、23.2.0のサーバー・クライアントとそのままつながる）。Scratchのブロック選びにマイクラ26.3の日本語の名前を追加。Scratch LANパッケージのはじめに.htmlをOSごとの手順に整理。不具合や気づいたことはフィードバックのフォームへ。
  • 2026年10月14日Protocol 23.2.0 (b10)
    McRemoteを一つのJAR（mc-remote-2320.0.0b10.jar）でPaper 1.21.11と26.3に対応し、tagとJARの名前からMinecraftの版を外した。setBlocksの大きな要求（既定で1要求32768ブロックまで）を複数tickに分けて施工。Scratch LANパッケージ（Scratch、ランチャーと設定画面、WireScopeを同梱したOS別ZIP）を追加。APIの変更はなし。
  • 2026年10月5日Protocol 23.2.0 (b9)
    APIフリーズ。chat.postの成功時の応答をnullに固定し、知らない種類のイベントが届いてもevents.poll全体を失敗させないように統一。PythonモジュールをPyPIへ登録（uv add "minecraft-remote-api==2320.0.0b9"）。プロトコル定義・WireScope・Bridgeをminecraft-remote-toolingへ移管。
  • 2026年10月3日Protocol 23.2.0 (b8)
    近くのエンティティの検索（getNearbyEntities）、エンティティの位置と向き・削除（entity.getPose / setPose / remove）、パーティクルの色・大きさと見せる相手（receiver）、サウンド（playSound / playBlockSound）。minecraft:を省いたIDの受け付けを全種類で統一。
  • 2026年9月3日Protocol 23.1.0 (b7)
    プレイヤーおよびエンティティの向き（getDirection / setDirection）の操作、落雷（strikeLightning）、WireScope detached ZIPの同梱。
  • 2026年8月28日Protocol 23.0.0 (b6)
    看板操作（getSign, setSign, updateSignLine）、ツルハシによるブロック叩きイベント（pickaxe_poke）、ブラウザ内自動保存（IndexedDB）の導入。
  • 2026年8月23日Protocol 22.0.0 (b5)
    構造化ブロック値（ブロックIDとブロック状態 state の分離）、空間識別子の Minecraft DimensionKey への統一、高速建築モード（DEBUG, TRACE, FAST）の整備。
  • 2026年8月18日Protocol 21.0.0 (b4)
    建築状態（ワールド＋原点）とプレイヤー識別の完全分離（setPlayer 廃止、setWorld / setBuildOrigin 導入）、向きを含むプレイヤー姿勢（getPose / setPose）の追加。
  • 2026年8月7日Protocol 21.0.0 (b3)
    生きたブロック／アイテム／パーティクルカタログの自動取得（catalog.get）と、型補完アーティファクト（mc_constants）の生成機構。
  • 2026年7月11日Protocol 21.0.0 (b2)
    安全なトークン認証およびワンタイム・ペアリング機構（/mcremote pair コマンド）の確立。
  • 2026年7月3日Protocol 21.0.0 (b1)
    通信ワイヤ形式を JSON-RPC 2.0 エンベロープへ全面刷新。多言語クライアント共通の基盤を確定。
