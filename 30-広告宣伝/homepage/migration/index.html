マイクラリモコン　／　旧版からの移行

🔄 旧版からの移行

2026年10月までのマイクラリモコンを使っていた方への案内です。新しいマイクラリモコンは、マイクラとプログラムの間の通信の決まり（プロトコル）が新しくなり、旧版とはつながりません。旧版のまま使える期間と、新しい版へ移る手順をまとめました。

🙋 対象の方 📅 予定 🐍 Python 🐱 Scratch 🖥️ マイクラサーバー

🙋 対象の方

マイクラリモコンは、時期によって次の構成で動いてきました。2026年10月までの構成を使っていた方が対象です。

時期 マイクラサーバーの側 Python Scratch
2021年7月〜2024年10月 RemoteControllerMod（Forgeのmod） Pythonモジュールmcje（MinecraftRemote） takecxさんの改造版Scratch
2024年10月〜2025年3月 JuicyRaspberryPie（プラグイン）。modも引き続き使う mcje 旧版の改造版Scratch（modとつなぐ）
2025年3月〜2026年10月 McRemote v1.21.8-1.4.0（プラグイン）。modも引き続き使う minecraft-remote-api 1214.10.11など1214系 旧版の改造版Scratch（modとつなぐ）
2026年11月から McRemote 2321.0.0（Paper 1.21.11、26.3のプラグイン） minecraft-remote-api 2321.0.0 マイクラリモコンのScratch 2321.0.0（箱庭のScratch、Scratch LANパッケージ）

2026年11月からの構成は、通信の決まり（プロトコル）が新しく、それより前の構成とはつながりません。これから始める方は、移行は要りません。はじめるへ進んでください。

📅 予定

初回Stableを公開する2026年11月1日に、箱庭サーバーの名前を切り替えます。sb.mc-remote.comは新しいプロトコルの安定版になり、旧プロトコルのサーバーはsb-retro.mc-remote.comとして11月末まで動かします。12月から、箱庭サーバーは新しいプロトコルに一本化します。

11月の間は、sb.mc-remote.comとsb-beta.mc-remote.comのどちらにつないでも、同じ安定版のサーバーにつながります。12月からは、ふだんは安定版のsb.mc-remote.comを使い、新しい機能を先に試したいときにベータ版のsb-beta.mc-remote.comを使います。

11月1日からは、旧版のScratchやPythonでsb.mc-remote.comにつなごうとしても、つながりません。旧版を使い続ける間は、つなぎ先をsb-retro.mc-remote.comに変えてください。

時期 sb.mc-remote.com sb-retro.mc-remote.com sb-beta.mc-remote.com
2026年10月31日まで 旧プロトコル ― 新しいプロトコル（リリース候補版）
2026年11月1日〜30日 新しいプロトコルの安定版 旧プロトコル 新しいプロトコルの安定版
2026年12月から 新しいプロトコルの安定版 終了 新しいプロトコルのベータ版

初回Stable（2026年11月）を公開すると、Pythonで版を指定せずに入れたときに入る版も、新しい版に変わります（下の「Python」）。

🐍 Python

何が変わるか

初回Stableの公開の後、版を指定しないpip install minecraft-remote-apiやuv add minecraft-remote-apiで入るのは、新しい版（2321.0.0）になります。新しい版は旧プロトコルのサーバーにはつながりません。また、旧版のプログラムは、接続のしかたなどが変わるため、そのままでは動かないものがあります。

旧版を使い続ける（2026年11月まで）

旧プロトコルの箱庭サーバーや、旧版のmodを入れたサーバーにつなぐ間は、旧版を版を指定して入れてください。11月1日からは、箱庭サーバーのつなぎ先をsb-retro.mc-remote.comに変えてください。

pip install "minecraft-remote-api==1214.10.13"

新しい版へ移る

mcjeを使っていた方も、新しいminecraft-remote-apiへ移ります。新しい版では、Pythonの環境とパッケージの管理にuvを使います。pyenvやpoetryを使っていた方も、uvへ移ると手順が短くなります。

  1. uvを入れます（手順はuvの公式の案内にあります）。
  2. 作業用のフォルダーで、uv init --no-packageを実行します。
  3. uv add minecraft-remote-apiで新しい版を入れます。
  4. トップページのPythonでのHello, world!のhello.pyを、uv run hello.pyで動かします。初めてつなぐときは、マイクラのチャットでペアリングします。

くわしい手順は、minecraft-remote-apiのREADMEにあります。使える命令はAPI一覧で確かめられます。

🐱 Scratch

旧版の改造版Scratch（マイクラ1.12.2用、1.16.5用）とRemoteControllerModから、新しいScratchへ移ります。新しいScratchはmodを使わず、マイクラサーバーのMcRemoteとつながります。拡張機能が新しくなり、ブロックも変わっています。ブロックはScratchのブロック一覧で確かめられます。

  • 箱庭サーバーで使う：ブラウザで箱庭のScratchを開きます。手順ははじめるにあります。
  • 自分のワールドで使う：Scratch LANパッケージを使います。

🖥️ マイクラサーバー

Forgeのmod（RemoteControllerMod）、JuicyRaspberryPie、旧版のMcRemote（v1.21.8-1.4.0など）から、Paperサーバーと、そこへ入れる新しいプラグインMcRemote（2321.0.0）へ移ります。対応するマイクラの版は1.21.11と26.3です。準備のしかたはMcRemoteのREADMEにあります。
